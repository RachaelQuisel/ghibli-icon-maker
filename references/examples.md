# Model outcomes

The three icons this skill was built from. New icons should feel inevitable next to these: one contour language, generous empty field, total discipline. Open the bundled PNGs with an image viewer before drawing.

## worth-asking
- Palette: blue-grey wash (top 229,238,239 / bottom 190,212,218), glow 255,246,224.
- Subject: speech bubble drawn as one continuous contour with a hand-drawn tail; a loose question mark inside (hook, stem, dot).
- Accent: sparkle top-right.
- Visual reference: [worth-asking.png](images/worth-asking.png)

## github-portfolio-creator
- Palette: peach/clay (top 251,239,222 / bottom 235,206,180), glow 255,247,223.
- Subject: browser card (rounded rect, rule, two window dots) holding a person glyph and three text rules.
- Accent: sparkle top-right.
- Visual reference: [github-portfolio-creator.png](images/github-portfolio-creator.png)

## secure-your-data
- Palette: sage (top 234,238,219 / bottom 196,209,185), glow 255,250,226.
- Subject: padlock (shackle arc over a rounded body), keyhole circle with stem, three dots below.
- Accent: sparkle top-right.
- Visual reference: [secure-your-data.png](images/secure-your-data.png)

## turn-off-ai-data-sharing
- Palette: blush-mauve (top 248,236,238 / bottom 216,188,198), glow 255,246,237.
- Subject: toggle switch drawn as a capsule, knob outlined at the left so it reads as off; three dots in the empty half of the track.
- Accent: sparkle top-right.
- Visual reference: [turn-off-ai-data-sharing.png](images/turn-off-ai-data-sharing.png)
